Default 1.06 overscans ~6% past the postcard edges so USB SELPHY prints don’t show a thin white border. Use 1.03–1.08 if you still see white or too much crop.

USB (recommended / backup)

Plug SELPHY in by USB and choose the queue whose driver name contains Canon / SELPHY. That path is confirmed correct for color + 6×4.

Wi‑Fi / IPP (fix if wrong)

Windows “IPP” or “Microsoft IPP Class Driver” queues often print grayscale, portrait, and crop badly. That is a driver problem — not the booth app. To use Wi‑Fi correctly:

  1. Install the official Canon SELPHY CP1500 driver/software from Canon.
  2. In Windows Printers & scanners, remove the IPP/WSD SELPHY queue if it misbehaves.
  3. Add the printer again with the Canon driver on a Standard TCP/IP port (SELPHY’s IP), not “Internet Printing Protocol”.
  4. Refresh printers here and select that Canon Wi‑Fi queue — or keep USB as the booth default.
