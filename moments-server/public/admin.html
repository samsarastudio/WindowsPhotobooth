Photo frames

Booth overlays on this server. Windows photobooth auto-publishes uploads and Sync pushes local frames here; Sync / guest frame picker pulls changes back to the booth. Prefer landscape PNG overlays with a transparent (or black) photo hole and no caption text bar. A starter file ships in seed-frames/botanical-landscape.png — upload it here (or Publish from the booth) so all booths Sync the same matte.

Mosaic wall

Guest photos collage on a filled wall with motion. At the end of the show, switch to a completed filled grid. Backdrop artwork sits in the middle of the wall and peeks through when photos swap. Brand partner reveal can blur the wall and overlay a logo on a timer. Cards stay 6×4. Open /wall.

Live collage — photos float and swap during the event.

Backdrop (behind the wall)

Sits in the middle of the wall under the photos. Guests glimpse the brand when tiles swap or lift. Click Upload after choosing a file.

Brand partner reveal

Periodically blurs the live wall and shows the partner logo on top. Turn this off to disable the overlay entirely. The small header chip next to inmoment still uses the same logo.

Booth updates

Upload a PhotoBooth Folder zip from builds/PhotoBooth-Folder-…zip (created by the Windows build). Click Roll out to publish it. Each booth installs manually from Photobooth Admin → Gallery → Install update (app quits, replaces files, keeps config / capture / data, then relaunches).

Upload release

Production Moments runs on the Pi behind Cloudflare (moments.inmomentservices.com). Prefer small-chunk browser upload after the Pi has pulled latest moments-server. If a ~150 MB zip still stalls, copy the zip onto the Pi and register locally (bypasses Cloudflare body limits): scp zip pi@HOST:~/moments-server/incoming/ then on the Pi node scripts/register-booth-zip.mjs ~/moments-server/incoming/….zip → Admin Refresh → Roll out.
