# Ready-to-install booth skins

These versioned data-only ZIPs require **PhotoBooth 1.3.0 or newer**.

- `christmas-1.0.0.booth.zip` — Christmas, including family cards.
- `halloween-1.0.0.booth.zip` — original HauntBooth package.
- `sports-cricket-1.1.0.booth.zip` — latest: three distinct broadcast settings, each with close/medium/wide depth plates; Classic photo uses a normal black-backdrop preview.
- `sports-cricket-1.0.0.booth.zip` — previous edition, retained for rollback.

Upload in Moments `/booth-packages.html`, publish, then download/apply from booth **Admin → Themes**. Or use **Import package ZIP** offline. Downloading does not activate a skin.

See `moments-server/docs/booth-packages.md` for deployment, compatibility, security limits, rollback and authoring instructions. Companion manifests list exact content hashes. Never modify an already published ZIP; increment its version instead.
