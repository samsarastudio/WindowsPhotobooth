# Ready-to-install booth skins

These versioned data-only ZIPs require **PhotoBooth 1.3.0 or newer**.

- `christmas-1.0.0.booth.zip` — Christmas, including family cards.
- `halloween-1.0.0.booth.zip` — original HauntBooth package.
- `sports-cricket-1.2.7.booth.zip` — latest: enlarged exact KWCA badge at lower left; continuous artwork to outer edges, with smaller ball and rich ornamental detail in both orientations.
- `sports-cricket-1.2.4.booth.zip` — previous: detailed ornamental KWCA frames with smaller cricket balls, original supplied logo, blended transparent edges and orange/gold cricket artwork in both orientations.
- `sports-cricket-1.2.1.booth.zip` — previous: KWCA landscape and portrait frames in orange/yellow jersey colours; all five settings and fifteen depth plates preserved.
- `sports-cricket-1.2.0.booth.zip` — previous: adds KWCA Trophy Gallery and KWCA Players Pavilion with dimensional branding and six depth plates; retains all three original cricket settings.
- `sports-cricket-1.1.0.booth.zip` — previous: three distinct broadcast settings, each with close/medium/wide depth plates; Classic photo uses a normal black-backdrop preview.
- `sports-cricket-1.0.0.booth.zip` — previous edition, retained for rollback.

Upload in Moments `/booth-packages.html`, publish, then download/apply from booth **Admin → Themes**. Or use **Import package ZIP** offline. Downloading does not activate a skin.

See `moments-server/docs/booth-packages.md` for deployment, compatibility, security limits, rollback and authoring instructions. Companion manifests list exact content hashes. Never modify an already published ZIP; increment its version instead.
